Enunciado

O herói carrega uma mochila cheia de itens, mas só os lendários contam na hora da batalha final. Implemente o método calcularPoderTotal que recebe uma lista de itens e devolve a soma do poder de todos os itens cuja raridade seja LENDARIA.

Use a Streams API do Java — nada de laços for manuais. A solução ideal cabe em uma única expressão fluente.

Requisitos
  • Filtrar apenas itens com raridade LENDARIA
  • Somar o campo poder (inteiro) dos itens filtrados
  • Retornar 0 quando a lista estiver vazia
  • Resolver com stream() — sem loops explícitos
